# ระบบบริการหลังการขาย CiViO — คู่มือสั้น

เปิดที่ `service/index.html` (หรือเมนู "หลังการขาย" บนเว็บ)

## บัญชีทดลอง (รหัสผ่านทุกบัญชี `civio1234`)
กดปุ่มในหน้าเข้าสู่ระบบเพื่อเข้าได้เลย — ระบบ **ไม่มีข้อมูลทดลอง** มีเฉพาะบัญชี

| บัญชี | บทบาท |
|---|---|
| exec@civio.demo | ผู้บริหาร (ทำได้ทุกอย่าง) |
| sales@civio.demo | ทีมขาย |
| tech@civio.demo | ทีมช่าง |
| hotel@demo.th | ลูกค้า (ยังไม่ผูกกับองค์กร: เปิดหน้าลูกค้า → "ผูกบัญชีทดลองลูกค้า") |

**ก่อนใช้จริง:** ตั้งค่า → ผู้ใช้ → สร้างบัญชีผู้บริหารของตัวเอง → ออกแล้วเข้าด้วยบัญชีใหม่ → "ปิดบัญชีทดลองทั้งหมด"

## เริ่มใช้งาน
1. กด **+ เพิ่ม** (มุมขวาบน) → **ส่งมอบเครื่องใหม่** → ลูกค้า → เครื่อง → ตรวจสอบ
2. ระบบลงปฏิทินให้: ตรวจเช็กครั้งถัดไป รายการเช็กตามรอบ วันหมดประกัน
3. นัดงานจาก **ปฏิทิน** (กดวัน → นัดงาน) หรือ **+ เพิ่ม → นัดหมาย / แจ้งซ่อม** จะเห็นคิวของวันนั้นก่อนบันทึก
4. ช่างกด **อัปเดตงาน** → เลือกสถานะ "เสร็จสิ้น" → ระบบบันทึกการตรวจและนับรอบถัดไปให้

## ใครเพิ่ม/แก้/ลบอะไรได้
| ข้อมูล | ผู้บริหาร | ทีมขาย | ช่าง | ลูกค้า |
|---|---|---|---|---|
| ลูกค้า / เครื่อง (เพิ่ม แก้ ลบ) | ✓ | ✓ | ดูอย่างเดียว | ดูของตัวเอง |
| เปิดงาน / นัด / เลื่อน / ยืนยันนัด | ✓ | ✓ | ✓ | แจ้งซ่อมและขอนัด |
| อัปเดตสถานะ / ลบงาน / การตรวจเช็ก / อะไหล่ | ✓ | – | ✓ | – |
| ยอดขาย | ✓ | ✓ | – | – |
| อนุมัติ / สร้างบัญชีลูกค้า | ✓ | ✓ | – | สมัครเอง |
| บัญชีทีมงาน รุ่นเครื่อง อาการ รายการเช็ก ตั้งค่า | ✓ | – | – | – |

**ลบไม่ได้ (กันข้อมูลประวัติหาย):** ลูกค้าที่ยังมีเครื่อง · เครื่องที่มีประวัติงาน · อะไหล่ที่ถูกใช้แล้ว · รุ่นที่มีเครื่องใช้อยู่ · บัญชีตัวเอง · ผู้บริหารคนสุดท้าย

**เพิ่มจากหน้าเว็บไม่ได้ (ต้องแก้โค้ด):** สถานะงาน ระดับความเร่งด่วน บทบาทผู้ใช้ เมนูของแชตบอท LINE และรายการอาการในแชตบอท (`line-gateway/webhook.php`)

## ระบบอัตโนมัติ (ตั้งค่า → อัตโนมัติและแจ้งเตือน)
| เรื่อง | ทำเมื่อไร |
|---|---|
| คำนวณวันหมดประกันและรอบตรวจเช็กลงปฏิทิน | ทันทีที่บันทึกเครื่อง |
| สร้างงานตรวจเช็กล่วงหน้า (เลือกวันว่าง + ช่างงานน้อยสุด) | เหลือไม่เกิน 14 วัน — สถานะ "รอยืนยันนัด" ทีมงานต้องกดยืนยัน |
| เตรียมข้อความแจ้งเตือน LINE | เปิดระบบ / ทุกชั่วโมง (เชื่อม LINE แล้วจะส่งทันที) |
| บันทึกการตรวจและนับรอบใหม่ | ปิดงานตรวจเช็ก |
| ตัดสต็อกอะไหล่ / คืนสต็อกเมื่อลบงาน | บันทึกงาน |

**ข้อจำกัด:** อัตโนมัติฝั่งเว็บทำงานเฉพาะตอนมีทีมงานเปิดระบบค้างไว้ ถ้าต้องการส่งทุกเช้าโดยไม่ต้องเปิดเว็บ ใช้ `line-gateway/cron-daily.php` (ต้องมี MySQL)

## สถานะปัจจุบัน — อ่านก่อนใช้จริง
- ข้อมูลเก็บในเบราว์เซอร์ (localStorage) ของเครื่องที่เปิด **ยังไม่แชร์ข้ามเครื่อง/ข้ามคน** ให้คนเดียวกรอกบนเครื่องเดียว และสำรองข้อมูลเป็นประจำ (ตั้งค่า → ข้อมูล)
- **การเข้าสู่ระบบยังไม่ใช่ความปลอดภัยจริง** ก่อนใช้กับลูกค้าจริงต้องย้ายล็อกอินและข้อมูลไปเซิร์ฟเวอร์ (ตาราง `users` ใน `database/schema.sql`)
- ถ้าเบราว์เซอร์เคยมีข้อมูลตัวอย่างจากรุ่นเก่า ระบบจะล้างเฉพาะข้อมูลตัวอย่างนั้นตอนเปิดครั้งแรก

## สำหรับผู้พัฒนา
| ไฟล์ใน `js/` | หน้าที่ |
|---|---|
| `core.js` | ข้อมูล กฎประกัน/ตรวจเช็ก ระบบอัตโนมัติ คิว LINE (เปลี่ยน `load()/save()` เมื่อย้ายไปเซิร์ฟเวอร์) |
| `ui.js` | หน้าต่าง ฟอร์ม ตาราง ป้ายสถานะ |
| `calendar.js` | ปฏิทิน ตัวเลือกวันนัด ไฟล์ .ics |
| `views.js` | หน้าแต่ละเมนู |
| `forms.js` | ฟอร์มเพิ่ม/แก้ไข |
| `app.js` | สิทธิ์ ปุ่ม การเข้าสู่ระบบ เริ่มทำงาน |

แก้ไฟล์ JS/CSS แล้วให้เพิ่มเลข `?v=` ใน `index.html` เพื่อไม่ให้เบราว์เซอร์ใช้ไฟล์เก่า
