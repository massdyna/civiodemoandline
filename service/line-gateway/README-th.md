# LINE แจ้งเตือน + แชตบอท CiViO

ทำอะไรได้
- **แจ้งเตือนเป็นการ์ดสวย (Flex Message)**: ใกล้หมดประกัน · ถึงรอบตรวจเช็ก · **เตือนนัดหมายล่วงหน้า** · **ถึงกำหนดเช็กรายการอื่นของสินค้า** · อัปเดตสถานะงานซ่อม พร้อมปุ่มกดตอบ
- **แชตบอท**: ลูกค้ากดเมนู/พิมพ์ได้ — เช็กประกัน · แจ้งซ่อม (เลือกเครื่อง → อาการ → ยืนยัน) · ติดตามงาน · นัดตรวจเช็ก · ให้คะแนน · ดูสินค้า · ติดต่อเรา
- **Rich Menu** 6 ปุ่มใต้ช่องแชต · แจ้งเตือนทีมงานทาง LINE เมื่อมีงานใหม่
- ผูกบัญชีลูกค้าด้วยรหัสใช้ครั้งเดียว (ปลอดภัยกว่าให้ลูกค้าพิมพ์เบอร์โทรเอง)

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|

| `make-bind-code.php` | ออกรหัสผูกบัญชีให้ลูกค้า |

| `flex.php` `lib.php` `config.php` | ตัวช่วยภายใน |

## ระวังข้อความซ้ำ
หน้าเว็บหลังการขายมีตัวเลือก “เตรียมข้อความแจ้งเตือนอัตโนมัติ” และ `cron-daily.php` ก็ส่งแจ้งเตือนเองจาก MySQL สองฝั่งกันซ้ำแยกกัน ถ้าเปิด cron แล้วให้ปิดตัวเลือกในหน้าเว็บ (ตั้งค่า → อัตโนมัติและแจ้งเตือน)

## ติดตั้งบนโฮสติ้ง (DirectAdmin / PHP 7.4+ มี cURL, PDO MySQL)
1. **LINE Developers** → สร้าง Messaging API channel (ผูกกับ LINE Official Account) จดค่า *Channel secret* และออก *Channel access token (long-lived)*
2. **ฐานข้อมูล**: DirectAdmin → MySQL Management สร้างฐานข้อมูล+ผู้ใช้ → phpMyAdmin นำเข้า `../database/schema.sql` แล้วตามด้วย `schema-line.sql` และ `schema-reminders.sql`
3. **ตั้งค่า**: คัดลอก `config.sample.php` เป็น `config.local.php` กรอกค่า (โทเคน, secret, ฐานข้อมูล, `CIVIO_SHARED_SECRET` สุ่มยาว ๆ) — แนะนำให้วางไฟล์นี้นอก `public_html` ถ้าทำได้
4. **อัปโหลด** โฟลเดอร์ `service/` ทั้งหมดขึ้นโฮสต์ (ต้องเป็น HTTPS)
5. **Webhook**: LINE Developers → Messaging API → Webhook URL = `https://civio.co.th/service/line-gateway/webhook.php` → กด Verify → เปิด *Use webhook*
6. **LINE Official Account Manager** → ตั้งค่าการตอบกลับ: ปิด "ข้อความตอบกลับอัตโนมัติ" และ "ข้อความต้อนรับ" (ให้บอทตอบแทน)
7. **Rich Menu**: เปิด SSH/Terminal หรือใช้ DirectAdmin Cron Jobs รันครั้งเดียว: `php .../line-gateway/setup-richmenu.php`
8. **ตั้ง Cron รายวัน** (DirectAdmin → Cron Jobs): `0 8 * * *  php /home/USER/domains/civio.co.th/public_html/service/line-gateway/cron-daily.php`
9. หน้า **ตั้งค่า** ในระบบหลังการขาย: ใส่ LINE OA ID, URL ประตูส่ง (`.../send.php`) และรหัสลับ = `CIVIO_SHARED_SECRET`

## แจ้งเตือนนัดหมายล่วงหน้า และเช็กรายการอื่นของสินค้า
cron-daily.php ส่งเพิ่ม 2 แบบ (ปรับตัวเลขได้ที่ต้นไฟล์ `cron-daily.php`)
| แบบ | ส่งเมื่อ | ตั้งค่า |
|---|---|---|
| เตือนนัดหมาย | งานที่ทีมช่างกำหนด "วันนัด" ไว้และยังไม่ปิดงาน เหลือไม่เกิน N วัน (ถ้าใส่เวลานัดจะแสดงในการ์ดด้วย) | `$APPT_NOTICE = [3]` — ใส่ `[3, 1]` ถ้าอยากเตือนอีกครั้งก่อนวันนัด 1 วัน |
| ถึงกำหนดเช็กรายการอื่น | รายการในตาราง `check_items` (เช่น เปลี่ยนไส้กรอง ทุก 6 เดือน) ครบกำหนดภายใน N วัน นับจากครั้งล่าสุดที่บันทึก ถ้ายังไม่เคยบันทึกนับจากวันติดตั้ง | `$CHECK_NOTICE = 3` และแก้ชื่อ/ทุกกี่เดือนในตาราง `check_items` |

- เลื่อนวันหรือเวลานัด → ระบบเตือนใหม่ให้อัตโนมัติ (กันซ้ำด้วยวัน+เวลานัด) ส่วนนัดที่ปิดงานแล้วจะไม่เตือน
- ตอนบันทึกการตรวจเช็กให้เลือก "รายการที่ตรวจ" ให้ตรงกับรายการ จึงจะเริ่มนับรอบถัดไปใหม่
- **ครั้งแรกที่เปิดใช้กับข้อมูลจริง** เครื่องที่ติดตั้งมานานแล้วแต่ยังไม่เคยบันทึกรายการเช็กนั้น จะได้ข้อความ "เลยกำหนด" ทันที — ควรบันทึกประวัติการเช็กที่เคยทำไว้ก่อน หรือทดสอบส่งหาทีมงานก่อนเปิดให้ลูกค้า
- ค่า `check_items` ที่ให้มาเป็นตัวอย่างเริ่มต้น ปรับให้ตรงกับรอบบำรุงรักษาจริงของเครื่อง

## ผูกบัญชีลูกค้า
1. ทีมขายออกรหัส: `php make-bind-code.php <customer_id>` (หรือ POST `{secret, customer_id}` ไปที่ไฟล์เดียวกัน)
2. ลูกค้าเพิ่มเพื่อน OA แล้วพิมพ์ `ผูกบัญชี ABCD2345` (ใช้ได้ครั้งเดียว หมดอายุ 7 วัน ใส่ผิดเกิน 5 ครั้งจะล็อก)
3. คนในองค์กรเดียวกันผูกได้หลายคน (ออกรหัสใหม่ให้แต่ละคน)

## ทีมงานรับแจ้งเตือนงานใหม่
ให้ทีมงานเพิ่มเพื่อน OA และพิมพ์อะไรก็ได้ 1 ครั้ง → ดู User ID ที่ตาราง `line_contacts` → ใส่ใน `STAFF_LINE_IDS`

## ข้อควรรู้ — อ่านก่อนใช้จริง
- **บอทและ cron อ่านข้อมูลจาก MySQL** ส่วนหน้าเว็บหลังการขายตอนนี้ยังเก็บในเบราว์เซอร์ จึงต้องย้ายข้อมูลก่อน: ส่งออก JSON (ตั้งค่า → ข้อมูล → สำรองข้อมูล) แล้วรัน `php import-json.php ไฟล์.json` — งานที่ลูกค้าแจ้งผ่าน LINE จะเข้า MySQL แต่ยังไม่โผล่ในหน้าเว็บจนกว่าจะทำ API ตามแผนใน `../README-th.md`
- แจ้งเตือนที่สั่งจากหน้าเว็บผ่าน `send.php` ทำงานได้ทันที (ไม่ต้องมี MySQL) แต่ปุ่ม "แจ้งซ่อม/ให้คะแนน" ในการ์ดจะใช้ได้เมื่อข้อมูลอยู่ใน MySQL แล้ว
- ข้อความ push นับโควตาตามแพ็กเกจ LINE OA — ตรวจโควตา/ราคาปัจจุบันกับ LINE ก่อนใช้งาน (ข้อความตอบกลับ reply ไม่นับโควตา)
- ลูกค้าต้องยินยอมรับข้อความ/เก็บข้อมูลส่วนบุคคล (PDPA) — ควรมีข้อความแจ้งในเว็บหรือตอนผูกบัญชี
- ตัวอย่างหน้าตาการ์ด: คัดลอก JSON ใน `flex.php` ไปลองที่ LINE Flex Message Simulator ได้
